LAYOUT NOTES
═══════════════════════════════════════════════════════════════

QuickSettingsLayout._getRows() flow:
  - Skips invisible children (visible=false → no row slot)
  - Skips the placeholder actor (overlay height sentinel)
  - Groups children into rows respecting nColumns=2 and column-span
  - vfunc_allocate: when a row contains any visible menu.actor,
    inserts overlayHeight gap below that row

Sub-menu positioning:
  QuickToggleMenu.actor constraints:
    Y = sourceActor.y + sourceActor.height  (BindConstraint + offset=height)
    X = fills full overlay width
  → Sub-menu appears directly below its owning tile row

Animation timing: POPUP_ANIMATION_TIME = 400ms (quickSettings.js:17)
  Open:  height 0→natural (200ms proportional) then opacity 0→255 (200ms)
  Close: opacity 255→0 (proportional) then height→0 (200ms) then hide()

PopupMenuManager:
  Each QuickSettingsItem with hasMenu:true creates its own _menuManager
  (PopupMenu.PopupMenuManager). This closes any open sub-menu when
  another opens. Dim effect applied to _boxPointer via BrightnessContrastEffect.
